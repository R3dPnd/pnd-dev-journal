# About This Project

This is a React-based developer journal application built with TypeScript and SCSS.

## Technology Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: SCSS with CSS custom properties for theming
- **Build Tool**: Create React App
- **Markdown**: File-based content loading

## Project Structure

```
client-app/
├── src/
│   ├── common/components/     # Reusable UI components
│   ├── pages/                # Page components
│   ├── sass/                 # SCSS styles and variables
│   └── constants/            # App constants and themes
├── public/                   # Static assets and markdown files
└── package.json
```

## Features

- ✅ Theme switching (light/dark mode)
- ✅ Responsive layout with sidebar navigation
- ✅ Markdown file reading and display
- ✅ Custom component library

## Development

To run this project locally:

```bash
npm install
npm start
```

The application will be available at `http://localhost:3000`
